# LeetCode Easy Solutions

A collection of solutions to LeetCode problems rated easy difficulty.

## Contents

Each problem is organized in its own directory, named with the problem number and title. The repository covers common topics such as arrays, strings, hashing, and basic problem-solving techniques.

## Usage

Clone the repository and open a problem directory:

```bash
git clone https://github.com/faizaanalam7388/LeetCode_Easy_Questions_Solutions.git
```

Use these solutions for practice and learning. Try solving each problem independently before comparing approaches.
